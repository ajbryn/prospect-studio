# Scoring rubric (0–100)

Score each lead on six factors, add the points, then apply an optional judgment adjustment.

| Factor | Points | How to award |
|---|---|---|
| **Segment fit** | 0–25 | 25 = clearly in a target segment (e.g., a 3PL warehouse, electrical contractor); 18 = adjacent (e.g., a wholesaler with its own warehouse); 8 = weak; 0 = not a fit |
| **Facility fit** | 0–20 | Evidence of high ceilings, racking, dock doors, fabrication bays, cranes, mezzanines, rooftop/ceiling equipment, or installation work at height. 20 = explicit; 12 = likely; 6 = unknown; 0 = unlikely (small office, retail storefront) |
| **Buying signals** | 0–25 | Cited signals from the last 12 months: permit, expansion or new site, hiring for lift/maintenance/installer roles, new contract, funding. 25 = two or more; 15 = one; 0 = none. **Each must have a URL and date** |
| **Size** | 0–15 | Against the profile minimum (default 20 employees). 15 = clearly above; 9 = near or unknown-but-likely; 5 = unknown; 0 = clearly below |
| **Dealer coverage** | 0–5 | 5 = in a dealer territory within ~25 miles of a branch; 3 = covered but farther away; 0 = no coverage |
| **Data confidence** | 0–10 | 10 = website + address confirmed + multiple sources; 6 = two sources; 3 = a single source |
| **Judgment adjustment** | −10…+10 | Optional. Must be explained in the rationale (e.g., "+6: permit names aerial work platforms"; "−8: cold storage needs special cold-rated units") |

**Tiers:** A ≥ 80 · B 65–79 · C < 65. Without buying signals the maximum is 75, so **a tier-A lead always has cited evidence**, which is intentional.

**Rationale:** 1–2 sentences that reference the signals, e.g., *"Expanding high-bay warehouse (180k sq ft permit, Jul 2026) and hiring maintenance techs with lift certification."*

## Worked example
| Factor | Bayou Fulfillment (3PL, Katy) |
|---|---|
| Segment | 25 |
| Facility | 20 (website: 32-ft clear height, 14 docks) |
| Signals | 25 (permit Jul 2026; lift-certified job post Sep 2026) |
| Size | 15 (~140 employees) |
| Dealer | 5 (Gulf Lift, West Houston branch, 8 mi) |
| Confidence | 10 |
| Adjustment | 0 |
| **Total** | **100 → tier A** |
