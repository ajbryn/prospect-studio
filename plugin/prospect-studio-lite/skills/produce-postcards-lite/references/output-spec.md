# Output spec

## Campaign folder layout
```
Campaigns/<yyyy-mm> <Name>/
├─ profile.md, candidates.csv, research.jsonl, leads.xlsx      (from find-leads-lite)
├─ design/  variants.json, previews/*.png, changes.md, template.json   (from design-postcards-lite)
├─ codes.csv          LeadId,Code,OfferCode,Url            (append-only; codes never change)
├─ cohorts.csv        LeadId,Tier,Dealer,Cohort            (optional)
├─ postcards/
│  ├─ cards.json
│  ├─ print/<LeadId>_<Company>.pdf     2 pages, 9.25 x 6.25 in (6x9 trim + 0.125 in bleed)
│  ├─ email/<LeadId>_<Company>.png     front only, trimmed to 6x9
│  ├─ proofs.pdf                       every card, front + back, for sign-off
│  └─ qa-report.json
├─ dealers/<Dealer name>/ lead-packet.html, lead-packet.pdf, leads.xlsx
└─ mailing/manifest.csv
```

## Tracking codes
- 6 characters from `23456789ABCDEFGHJKLMNPQRSTUVWXYZ` (no 0/O/1/I), generated by `render_postcards.py codes`.
- Unique across all campaigns in the workspace: pass every campaign's `codes.csv` codes as `--existing`. Concatenate them into a temp file first if there are several.
- `OfferCode = <offerPrefix>-<Code>` (e.g., `LIFT-K7Q3MX`); `Url` = template `urlPattern` with `{code}` replaced.

## "Mail later" split (optional)
- Group approved leads by (Tier, Dealer). Within each group, sort by a random key and assign the first half, rounded up, to `wave1` and the rest to `wave2`.
- Record the random seed (e.g., the campaign name plus date) in `cohorts.csv`'s header comment, so the split can be reproduced.
- Produce `wave1` now. Tell the user to mail `wave2` 6–8 weeks later, and to compare responses and warranty registrations between the waves in the meantime.

## `mailing/manifest.csv`
```
LeadId,Company,Attn,Address1,City,State,ZIP,DealerId,Dealer,Code,OfferCode,Url,Cohort,PrintPdf,EmailPng
```

## Dealer `leads.xlsx` (Google-Sheets-compatible: plain ranges, dropdown via inline list validation)
| Column | Notes |
|---|---|
| LeadId, Company, Address, City, ZIP, Tier, Score | From the campaign |
| Why now | Rationale + top signal |
| Suggested angle, Contact roles | From research |
| Code | Offer code on the card |
| Outcome | Dropdown: New, Contacted, Meeting/Demo, Quote sent, Won, Lost, Not a fit, Already a customer |
| Date contacted, Units, Model, Value, Notes | For the dealer to fill in |

## Dealer `lead-packet.html`
Letter size, one lead per page (`page-break-after: always`), simple readable styling: company and address at the top, then a card thumbnail (`<img>` pointing at `../../postcards/email/<file>.png`), "Why now" with signal links, suggested angle, contact roles, and the offer code in large type.
