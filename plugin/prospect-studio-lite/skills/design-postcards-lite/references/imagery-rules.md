# Imagery rules

**Never use Google Street View, Google Maps or Google Earth imagery** on a postcard: no screenshots, no edits, no "inspired by" copies. Google's guidelines prohibit it in print and promotional material.

Allowed sources, in order of preference:
1. **The built-in illustrated scene** (default). It's drawn by the template, so it's license-safe by construction.
2. **The company's own product photos** (transparent cutouts from the marketing media kit) via `scene.productSrc`.
3. **Photos the company or its dealers took themselves**, via `scene.photoSrc`.
4. **Mapillary street imagery** (CC BY-SA 4.0), only with the credit line in `photoCredit`, and only if the user accepts the share-alike terms.
5. **Licensed stock or aerial imagery,** only if the user confirms the license covers print marketing.

Rules:
- Ask the user to confirm print rights for any image that didn't come from the brand kit or the built-in scene.
- Don't use the **prospect's logo** without the user's explicit OK. Their name as plain text on the illustrated sign is fine.
- Never let AI-generated imagery redraw the company's actual product. Use the real product cutout or the generic drawn lift.
